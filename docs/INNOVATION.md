# Pulse Trust — Pulse.mn-ийн ялгарах давхарга

Бусад мэдээний платформ «нийтэлсэн» гэдгээр дуусдаг бол Pulse.mn **нийтлэхээс өмнө болон нийтэлсний дараа**
баримтыг шалгадаг. Бүх шалгалт `backend/apps/ai/checks.py`-д, нэг шалгалт унасан ч бусад нь үргэлжилнэ.
Gemini түлхүүр байхгүй бол дүрэмд суурилсан хувилбараар ажиллана. **AI зөвхөн санал өгнө — шийдвэрийг редактор гаргана.**

| Шалгалт | Яаж ажилладаг | Gemini |
|---|---|---|
| Давхардал (текст) | 3 үгийн shingle Jaccard + гарчгийн төстэй байдал | — |
| Давхардал (утга) | `gemini-embedding-001` вектор, cosine ≥ 0.88 — үгийг нь солиод «дахин бичсэн» хуулбарыг барина | ✓ |
| Давхардал (зураг) | sha256 (яг ижил) + dHash перцептуал хэш (хэмжээ/формат өөрчилсөн ч Hamming ≤ 6) | — |
| **Тоон баримтын тулгалт** | Мэдээн дэх тоог («3 сая толгой мал») тухайн аймгийн албан ёсны статистиктай (`statistics` модуль) тулгаж, 10%-аас илүү зөрвөл тэмдэглэнэ | тоог ялгахад ✓ (дүрмийн fallback-тай) |
| Хувийн мэдээлэл | Утас, имэйл, регистрийн дугаар илрүүлж, нууцалж харуулна | — |
| Эх сурвалж, нотлох медиа, бүрэн байдал | Дүрэм | — |
| AI хяналт | Эргэлзээтэй хэсэг, дутуу баримтыг Монголоор тайлбарлана (prompt injection-ээс хамгаалсан) | ✓ |
| Амлалттай холбох санал | Мэдээний текст ↔ амлалтын текст/нэр | — |
| Итгэлцлийн оноо (0–100) | Шалгалтын үр дүнгийн нэгтгэл; нийтэд зөвхөн тоймыг харуулна | — |

## Урсгал
1. Сэтгүүлч илгээхээс өмнө **«Шалгах»** дарж өөрөө урьдчилан засна (AI-гүй, хурдан).
2. Илгээхэд автоматаар урьдчилсан шалгалт хадгалагдаж, хувилбар (v1, v2…) бүртгэгдэнэ.
3. Редактор «AI-аар гүнзгий шалгах» дарж Gemini-г нэмж ажиллуулна, зөрүүтэй тоог хүснэгтээр харна,
   өмнөх хувилбартай үгээр харьцуулна, шалгах жагсаалтыг баталгаажуулж байж нийтэлнэ.
4. Нийтлэгдсэн мэдээн дээр **Pulse Trust карт** — «Редактор баталгаажуулсан», албан ёсны тоотой тулгасан хүснэгт —
   иргэнд шалгаж болохуйц ил тод байдал өгнө.

## Хязгаарлалт (шударга байх үүднээс)
* dHash нь зөвхөн төстэй/өөрчилсөн зургийг барина; нүүр таних, deepfake илрүүлэлт биш.
* Тоон тулгалт нь зөвхөн админ бүртгэсэн үзүүлэлтээр ажиллана; үзүүлэлт нэмэх тусам хүчирхэгжинэ.
* Embedding дуудлага нь Gemini түлхүүр, квот шаардана; алдаа гарвал текстийн давхардал руу буцна.
